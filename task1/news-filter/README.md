# News Article Filter Application

## Installation

1. Clone this repository
2. Run `composer install` to set up autoloading
3. Point your web server to the `public` directory

## Usage

Access the application via your web browser. You can filter by category using the URL parameter:

- `?category=Business` (default)
- `?category=Finance`
- `?category=Travel`
- etc.

## Features

- Object-oriented design
- Type safety with strict typing
- Separation of concerns
- Clean template rendering
- Easy to extend
